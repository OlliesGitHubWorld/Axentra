Changelog

Everything that's changed in Axentra.

v1.6.0

Latest

October 2026 — Staff Management & Website Overhaul

Staff Management System

  • Staff Duty — /duty to toggle on/off duty with tracked sessions and duty time stats
  • Staffmode — /staffmode saves inventory, gives staff tools (random TP, freeze, invsee, history), and auto-vanishes
  • Player Reports — /report <player> <reason> with cooldown, chat log snapshots, and staff notifications
  • Reports GUI — /reports opens a GUI with all open reports; click to claim and teleport
  • Staff Stats — /staffstats [player|top] shows cases, bans, kicks, mutes, warns, reports closed, and duty time
  • Staff List — /stafflist shows all online staff with duty status indicators
  • Freeze System — Right-click players with the ice tool in staffmode to freeze/unfreeze them

Permission-based Announcements

  • Kick announcements now require Axentra.notify.kick instead of broadcasting to all players
  • Ban/tempban/unban/banip/tempbanip announcements now require Axentra.notify.ban instead of broadcasting to all players
  • Mute/unmute/tempmute already used Axentra.notify.mute (unchanged)
  • Warn already used Axentra.notify.warn (unchanged)

Config Auto-update

  • New config keys are automatically added to existing config.yml when updating the plugin — no more deleting your config to get new options
  • Works on server start, /axentra reload, and /plugman reload Axentra

Modular System — 13 Toggleable Modules

  • Every feature group can now be enabled/disabled in config.yml under enabled-modules
  • player-utilities — fly, heal, feed, god, speed, gamemode, clear, repair, hat, suicide, ping
  • vanish — vanish
  • invsee — invsee, enderchestsee
  • workbench-commands — anvil, workbench, cartography, grindstone, loom, smithingtable, stonecutter, enderchest
  • weather-time — weather, sun, rain, storm, time, day, night, noon, midnight
  • spawn — spawn, setspawn
  • back — back
  • tpa — tpa, tpaccept, tpdeny, tpacancel, tptoggle
  • chat-management — clearchat, mutechat, slowchat, staffchat + chat listener
  • messaging — msg, reply, msgtoggle
  • nickname — nick, realname, me
  • social-commands — discord, website, store
  • staff-management — duty, staffmode, report, reports, staffstats, stafflist
  • Moderation commands (kick, ban, mute, warn, case, history, etc.) are always enabled as core features

New Website

  • Completely redesigned website at axentramc.com
  • Homepage with features overview, screenshots, and download links
  • Full wiki with installation guide, commands, permissions, and configuration reference
  • Changelog page
  • Dark/light theme toggle
  • SEO optimized with sitemap, robots.txt, and meta tags
  • Mobile responsive design

v1.5.0

October 2026 — Smart Moderation Update

New Features

  • Punishment GUI — /punish <player> opens a click-to-punish GUI with customizable templates
  • Case System — Every punishment creates a tracked case with unique ID, viewable via /case <id>
  • History GUI — /history <player> shows color-coded cases with pagination
  • Staff Notes — /note add and /notes with automatic join notifications for staff
  • Audit Log — /auditlog <staff> tracks all staff actions with timestamps
  • Chat Log Snapshots — Last 20 messages per player attached to cases automatically
  • punishments.yml — New config file for punishment GUI templates

Bug Fixes

  • Fixed ban appeal link not showing when using the Punishment GUI
  • Fixed expiry dates displaying raw timestamps instead of formatted dates
  • Fixed tab completion only showing online players for moderation commands

Improvements

  • Offline players from the database now appear in tab completion
  • Added missing messages to messages.yml for workstations and help
  • Permission messages now show a proper error instead of being blank
  • Removed conflicting /r alias from repair command

v1.4.0

September 2026

New Features

  • Vanish System — Full vanish with ghost effect, fake join/quit, night vision, god mode, no pickup
  • God Mode — Toggle invincibility for yourself or others
  • Gamemode Shortcuts — /gms, /gmc, /gma, /gmsp
  • Speed Control — /speed <1-10> [walk|fly]
  • InvSee & EnderChestSee — View other players' inventories
  • Staff Settings GUI — In-game clickable menu for server settings
  • IP Banning — /banip and /tempbanip commands
  • Social Spy — Staff can see private messages between players
  • Nicknames — Persistent nicknames with color code support
  • TPA System — Full teleport request system with countdown
  • Virtual Workstations — Anvil, workbench, grindstone, loom, and more

Improvements

  • SQLite database for persistent storage
  • Configurable warn auto-punishments at thresholds
  • Muted command blocking is now configurable
  • Module toggles in config.yml
  • Built-in update checker
