Everything that's changed in Axentra.

v1.8.0

Latest

November 2026 — Server Health Update

Server Health

  • TPS & MSPT Monitoring — Built-in tick profiler that uses the Paper API when available, with a Spigot fallback. Tracks TPS over 1m, 5m and 15m, MSPT (average and peak over the last 100 ticks) and memory usage. TPS history is saved every minute and kept for 30 days by default
  • /lag — Overview of TPS, MSPT, memory, uptime, players, per-world stats and the health score, with clickable [Chunks], [Entities] and [History] buttons
  • /lag chunks — The 10 heaviest chunks, colored by score, with hover details, the player in each chunk and a clickable [TP] button. Only tile entities that actually do work count (hopper 5, spawner 3, furnace 2, …), players don't count, and chunks below score 10 are hidden
  • /lag entities — Entities per type with bars and categories, and a Normal / Elevated / High status based on the average per chunk and the busiest chunk
  • /lag history [hours] — TPS history GUI with 28 time blocks, hover details, a summary and period buttons (1h, 6h, 12h, 1d, 3d)
  • /lag player <name> — A player's lag-relevant activity over the last 7 days: placed hoppers, pistons and redstone, entity spawns and time per chunk
  • Health Score — A 0–100 score from TPS (40%), MSPT (20%), memory (15%), entities per chunk (15%) and reports + staff (10%), labeled Excellent, Good, Fair or Poor
  • TPS Alerts — Staff are alerted when TPS stays low, with the heaviest chunk, the biggest cause and clickable [Teleport] and [Lag] buttons, followed by a recovery message
  • Auto-Cleanup — Clears ground items every 10 minutes or only during a TPS alert, with warnings at 60s, 30s and 10s. Valuable and named items are never cleared. Manual cleanup with /lag clear [items|mobs|all]
  • Entity Limits — Per-chunk limits by type or group (ANIMALS, VILLAGER, ITEM_FRAME, …) that block new spawns and can optionally remove excess entities

Restarts & Maintenance

  • Scheduled Restarts — /restart now, /restart schedule <time> (with time suggestions), /restart cancel and /restart status, plus daily restart times with a timezone. Countdown with a bossbar, sounds, a title and warnings from 30 minutes down to 1 second. Supports pre-commands like save-all and Spigot's restart script
  • /restart now always runs Axentra's command. Spigot's built-in restart is available as /spigot:restart
  • Maintenance Mode — /maintenance on [duration] [-c countdown] [reason], off, status and add|remove <player>. Countdown with a bossbar, title and rising tick sounds, a custom MOTD and kick messages with placeholders (%reason%, %remaining%, %ends%, %discord%, …) and a hidden player count. Survives restarts and ends automatically after the given duration

Warps & Random Teleport

  • Warps — /setwarp, /delwarp, /warp and a paginated /warps GUI, with an optional permission per warp, a teleport delay that cancels when you move, and /back support
  • Edit warps in the GUI — Shift-click a warp to select it and click another warp to put it there (also across pages), press 1–9 to use that hotbar item as its icon, or press Q to rename it in chat
  • /editwarp <name> <icon|permission|order|rename> <value> — icon hand uses the item in your hand, material names tab-complete and invalid ones are rejected
  • Random Teleport — /rtp [world] (alias /wild) with per-world radius and center, Nether support below the bedrock roof, a safety check against lava, fire, cactus and void, and a 5-minute cooldown

Freeze & Punishments

  • /tempfreeze <player> <duration> — Players are unfrozen automatically when time runs out, even while offline
  • Frozen players can move within 1 block (movement-radius), and ender pearls and chorus fruit are blocked
  • Configurable [Frozen] tag above the head, in the tab list and in chat, plus snowflake particles and an action bar with the time left
  • logout-ban-reason and logout-ban-duration are now actually used (it used to always be a permanent ban)
  • Escalation — Punishment templates can escalate on repeat offenses (e.g. warn → warn → mute 30m). The GUI shows the next step in advance, and default ladders are included
  • New templates: Lag Machine Warning, Temp Ban (3d) and Permanent Ban
  • Warn punishments support a freeze action and ranges such as "1-10" or "10+"

Privacy & Performance

  • Fixed an IP leak: /banip <player> and /tempbanip <player> showed the player's IP to everyone with ban permissions. Axentra.alts.ip now controls IP visibility everywhere
  • Database runs in WAL mode with busy_timeout, so there are no more "database is locked" errors
  • Mute and freeze checks are cached, so chat and movement no longer hit the database
  • /history, /warns, /notes, /auditlog, /staffstats and /reports load their data asynchronously

Bug Fixes

  • Spigot's built-in restart took over /restart, so /restart schedule 60 restarted the server immediately
  • Error messages from /setwarp, /delwarp, /editwarp and /restart showed a literal &c instead of red text
  • /setwarp on an existing warp reset its icon and permission
  • The warps GUI could teleport you to the wrong warp when two players had it open
  • The [TP] button in /lag chunks used the wrong /tp command
  • Freeze reminders only started after the player rejoined, and message-interval-seconds was ignored

Upgrading

  • Fully restart the server — /reload is not enough. The new health.yml is created and existing configs get the new settings automatically
  • 9 new modules (30 in total) and 7 new database tables, upgraded automatically
  • data.db-wal and data.db-shm appear next to data.db. This is normal — don't delete them
  • If a staff group has Axentra.*, explicitly set Axentra.alts.ip to false where staff shouldn't see IPs
  • New permissions: Axentra.lag, Axentra.lag.clear, Axentra.lag.alerts, Axentra.restart, Axentra.maintenance, Axentra.maintenance.bypass, Axentra.setwarp, Axentra.delwarp, Axentra.warp, Axentra.warps, Axentra.editwarp, Axentra.rtp, Axentra.rtp.bypass, Axentra.entitylimit.bypass, Axentra.cleanup.bypass

v1.7.0

October 2026 — Player Protection Update

Player Protection

  • Inventory Snapshots — Automatic snapshots on death, join, quit, world change and /clear. Browse them per player in a paginated GUI, preview the contents and restore a full inventory with /restoreinv <player>
  • Trust System — NEW → MEMBER → TRUSTED based on playtime and a clean record, with configurable thresholds, restrictions for new players (links, caps, slowmode, msg) and automatic downgrades on punishments. View with /trust <player> or override with /trust set <player> <level>
  • Alt Detection — Accounts sharing an IP are detected automatically on join, with a risk score based on VPN status, trust level, banned alts and active cases. View them with /alts <player>
  • VPN Detection — Optional proxycheck.io check on join with ALERT or KICK action and result caching. The API key is set in protection.yml
  • Freeze — /freeze and /unfreeze block movement, block break/place, interaction, inventory, item drops, damage and commands, restrict chat to staff and repeat a reminder message. Stored in the database so it survives restarts, with frozen players re-frozen on rejoin and a configurable logout action (NONE/ALERT/BAN)
  • Player Timeline — /timeline <player> [filter] shows joins, quits, cases, deaths, name and IP changes
  • Smart Join Alerts — Staff see alts, VPN, trust level and open cases when a player joins, with clickable [Alts], [History] and [Timeline] buttons

Homes & Teleport

  • Homes — /sethome [name], /home [name], /delhome <name> and a paginated /homes [player] GUI with click-to-teleport, shift-click-to-delete and world-specific icons. Includes limits via Axentra.homes.<n>, teleport delay and world blacklist, and staff can view other players' homes
  • Teleport Commands — /tp <player> [player] to or between players, /tphere <player>, /tpall, /tpahere <player> to request a teleport to you, and /top to reach the highest block at your location

Moderation & Config

  • /case resolve <id> marks a case as resolved with an audit log, and /case delete <id> deletes it permanently
  • Clickable [History], [Resolve] and [Delete] buttons in case details
  • Kicks and warns now auto-resolve instead of staying active, and existing KICK/WARN cases are migrated on startup
  • New protection.yml for the VPN API key, freeze settings, snapshot triggers, trust thresholds and alt detection, plus 8 new modules (21 in total)
  • Config auto-updater rebuilt with template-based merging: new keys appear in the correct position with their comments, user values are preserved, and headers are no longer duplicated
  • Disabled modules now fully unregister their commands
  • New permissions: Axentra.restoreinv, Axentra.trust, Axentra.trust.admin, Axentra.alts, Axentra.alts.ip, Axentra.freeze, Axentra.freeze.exempt, Axentra.timeline, Axentra.case.delete, Axentra.sethome, Axentra.home, Axentra.home.others, Axentra.home.bypass, Axentra.delhome, Axentra.homes, Axentra.homes.others, Axentra.homes.unlimited, Axentra.tp, Axentra.tphere, Axentra.tpall, Axentra.tpahere, Axentra.top
  • After updating, delete your old messages.yml to regenerate it with the new protection and home messages

v1.6.0

October 2026 — Staff Management & Website Overhaul

Staff Management System

  • Staff Duty — /duty to toggle on/off duty with tracked sessions and duty time stats
  • Staffmode — /staffmode saves inventory, gives staff tools (random TP, freeze, invsee, history), and auto-vanishes
  • Player Reports — /report <player> <reason> with cooldown, chat log snapshots, and staff notifications
  • Reports GUI — /reports opens a GUI with all open reports; click to claim and teleport
  • Staff Stats — /staffstats [player|top] shows cases, bans, kicks, mutes, warns, reports closed, and duty time
  • Staff List — /stafflist shows all online staff with duty status indicators
  • Freeze System — Right-click players with the ice tool in staffmode to freeze/unfreeze them

Permission-based Announcements

  • Kick announcements now require Axentra.notify.kick instead of broadcasting to all players
  • Ban/tempban/unban/banip/tempbanip announcements now require Axentra.notify.ban instead of broadcasting to all players
  • Mute/unmute/tempmute already used Axentra.notify.mute (unchanged)
  • Warn already used Axentra.notify.warn (unchanged)

Config Auto-update

  • New config keys are automatically added to existing config.yml when updating the plugin — no more deleting your config to get new options
  • Works on server start, /axentra reload, and /plugman reload Axentra

Modular System — 13 Toggleable Modules

  • Every feature group can now be enabled/disabled in config.yml under enabled-modules
  • player-utilities — fly, heal, feed, god, speed, gamemode, clear, repair, hat, suicide, ping
  • vanish — vanish
  • invsee — invsee, enderchestsee
  • workbench-commands — anvil, workbench, cartography, grindstone, loom, smithingtable, stonecutter, enderchest
  • weather-time — weather, sun, rain, storm, time, day, night, noon, midnight
  • spawn — spawn, setspawn
  • back — back
  • tpa — tpa, tpaccept, tpdeny, tpacancel, tptoggle
  • chat-management — clearchat, mutechat, slowchat, staffchat + chat listener
  • messaging — msg, reply, msgtoggle
  • nickname — nick, realname, me
  • social-commands — discord, website, store
  • staff-management — duty, staffmode, report, reports, staffstats, stafflist
  • Moderation commands (kick, ban, mute, warn, case, history, etc.) are always enabled as core features

New Website

  • Completely redesigned website at axentramc.com
  • Homepage with features overview, screenshots, and download links
  • Full wiki with installation guide, commands, permissions, and configuration reference
  • Changelog page
  • Dark/light theme toggle
  • SEO optimized with sitemap, robots.txt, and meta tags
  • Mobile responsive design

v1.5.0

October 2026 — Smart Moderation Update

New Features

  • Punishment GUI — /punish <player> opens a click-to-punish GUI with customizable templates
  • Case System — Every punishment creates a tracked case with unique ID, viewable via /case <id>
  • History GUI — /history <player> shows color-coded cases with pagination
  • Staff Notes — /note add and /notes with automatic join notifications for staff
  • Audit Log — /auditlog <staff> tracks all staff actions with timestamps
  • Chat Log Snapshots — Last 20 messages per player attached to cases automatically
  • punishments.yml — New config file for punishment GUI templates

Bug Fixes

  • Fixed ban appeal link not showing when using the Punishment GUI
  • Fixed expiry dates displaying raw timestamps instead of formatted dates
  • Fixed tab completion only showing online players for moderation commands

Improvements

  • Offline players from the database now appear in tab completion
  • Added missing messages to messages.yml for workstations and help
  • Permission messages now show a proper error instead of being blank
  • Removed conflicting /r alias from repair command
